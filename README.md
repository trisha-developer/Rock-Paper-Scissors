# Rock Paper Scissors 🎮

A simple Rock Paper Scissors game built using **HTML, CSS, and JavaScript**.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## ✨ Features

* Player vs Computer
* Random computer choice
* Displays game result
* Simple and clean interface
